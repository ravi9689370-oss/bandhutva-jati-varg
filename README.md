## 📚 फाइल में क्या-क्या है

1. मुखपृष्ठ (वर्ण-पिरामिड चित्रण) — 2. प्रमाण-पत्र — 3. कृतज्ञता — 4. विषय-सूची — 5. प्रस्तावना
6. स्रोत-सामग्री और महाभारत का क्रिटिकल एडिशन (BORI पुणे, 1919–1966)
7. परिवार एवं बंधुता (कुरु-वंश वृक्ष) — 8. विवाह के आठ प्रकार, गोत्र, अनुलोम-प्रतिलोम
9. वर्ण-व्यवस्था (+ मेगस्थनीज के सात वर्ग) — 10. वर्ण के बाहर (चंडाल, मनुस्मृति नियम)
11. श्रमिकों का जीवन (दास, कर्मकार, तमिलकम्) — 12. संन्यासी परंपरा (थेरीगाथा)
13. बेगमपुरा : एक कल्पना — 14. स्त्रियाँ, संपत्ति और अधिकार (प्रभावती गुप्ता ताम्रपत्र)
15. समग्र दृष्टि (कालक्रम + आदर्श बनाम व्यवहार तालिका) — 16. निष्कर्ष — 17. संदर्भ सूची
